# KiCad PCB Designs

This folder serves as the central repository for all KiCad PCB designs across multiple years.  
Each subfolder corresponds to a specific design cycle and contains all associated board files, schematics, and documentation.

## Notes

- All boards should be designed in **KiCad** using consistent design rules.  
- Follow best practices for manufacturability, testing, and revision tracking.  
- Keep README files updated in each yearly folder to summarize the boards within.
